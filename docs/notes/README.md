# Notes for the integrator

Builders write here what `CLAUDE.md`, `docs/LAUNCH.md` or `docs/privacy-policy.md` should say, one file per branch (`docs/notes/<branch>.md`).
Only the integrator (the session that merges branches) edits those three files.
The integrator folds each note in and deletes it, so this folder is empty apart from this file,
`prompt-versions-inbox.md` (prompt lines that groups without prompt files left for the Prompt
versions group, kept until that group has written them) and `legal-<branch>.md` files: wording for
`docs/terms.md` and `docs/privacy-policy.md`, kept until the one legal release applies it
(`docs/LEGAL-RELEASE.md`).
