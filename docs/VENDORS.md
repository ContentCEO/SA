# Outside accounts

Every outside account Squared Away depends on, its plan, the limit that would stop the app, and
where to look. Numbers are the engineers' estimates from each company's published pages, not
quotes. This page names settings only; no key, password or token is ever written here. How to
check the free plans is in [LAUNCH.md](LAUNCH.md#check-your-free-plans-now-this-week).
